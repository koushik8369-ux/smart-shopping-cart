# Smart Shopping Cart

A simple Java console program for a shopping cart.

## Features

- View products
- Add products to the cart
- Remove products from the cart
- View cart and subtotal
- Checkout with discount

## Run the program

Open a terminal in this folder and run:

```bash
javac SmartShoppingCart.java
java SmartShoppingCart
```

## Discount rules

- Rs.0 to Rs.4,999: no discount
- Rs.5,000 to Rs.9,999: 5% discount
- Rs.10,000 and above: 10% discount
